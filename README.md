# IAM-Lab--SAML-Single-Sign-On-with-Microsoft-Entra-ID

Configured SAML-based Single Sign-On (SSO) for a custom enterprise application using Microsoft Entra ID. 

Tasks performed:
• Created enterprise application
• Configured SAML trust relationship
• Defined identifier and reply URL
• Configured attribute mapping
• Assigned users to the application
• Tested authentication flow
